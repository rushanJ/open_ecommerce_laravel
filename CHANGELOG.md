# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0-alpha

- Initial open-source alpha release
- Admin panel (catalog, orders, payments, settings, RBAC)
- Storefront (Blade + Tailwind)
- Product catalog (variants, attributes, inventory, media)
- Cart and checkout
- PayHere integration
- Orders and payments
- CMS (pages, menus, banners, SEO redirects)
- Reports and CSV export
- Customer API foundation (Sanctum) and Admin API (token-based read API)
- Product CSV import/export foundation
- Webhooks (outbound) and import job logging
- Backups (Spatie), installation and release check commands
